## Données fausses (`src/data/`) & état (`src/lib/`)
- `meubles.ts` : 8 meubles `{slug, nom, reference, duree, nbEtapes, difficulte, outils, piecesResume, requetePexels, image?}` ; commode-3-tiroirs = ref 000.000.10 (les autres refs/durées : fictives, `// TODO`).
- `guide.ts` : 15 étapes `{n, titre, texte, pieces, image?}` + `pieces` de la vérification. Tous les meubles réutilisent ce guide démo.
- État : un contexte client `AppState` (localStorage, try/catch) : `connecte`, `piecesCochees[slug]`, `montagesTermines[]`, `avis`. Toast global : un `ToastProvider` (file, auto-fermeture 3 s) monté dans le layout racine pour survivre aux navigations.
- Pexels : route `src/app/api/pexels/route.ts` (GET `?q=`) lit `process.env.PEXELS_API_KEY` côté serveur, appelle `https://api.pexels.com/v1/search?per_page=1&orientation=landscape`, renvoie `{url}` ; sans clé → `{url:null}` (placeholder). `FurnitureImage` essaie l'API (cache mémoire client), sinon placeholder. Ne jamais exposer la clé.

## Règles de qualité
Accessibilité : vrais `<button>/<a>/<input>`, `aria-*`, focus visible, contraste conforme aux tokens. Animations fidèles Figma : survol cartes/boutons (150 ms), ouverture modale (fondu + léger zoom), apparition toast, coche des pièces, progression. `prefers-reduced-motion` respecté (déjà dans globals.css). Pas de `any`, pas de hex en dur, pas de style inline sauf largeur dynamique de la barre. Vérifier : `npm run lint` + `npm run build` + page ouverte.
